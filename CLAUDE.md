This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Personal notes site built with Docusaurus 3.9, using bun as the package manager. Content is primarily mathematical notes written in Japanese with LaTeX math expressions.

## Commands

- `bun start` — Start local dev server with hot reload
- `bun run build` — Build static site to `build/`
- `bun run typecheck` — Run TypeScript type checking
- `bun run serve` — Serve the production build locally

## Architecture

- **docs/** — Markdown content organized by topic (e.g., `docs/books/`, `docs/memo/`). Sidebar is auto-generated from directory structure via `_category_.json` files.
- **docusaurus.config.ts** — Site config. Docs are served at root (`routeBasePath: '/'`). Blog is disabled. Math support enabled via `remark-math` + `rehype-katex`.
- **sidebars.ts** — Uses `autogenerated` sidebar from the `docs/` folder structure.
- **src/** — Custom React components and CSS overrides.

## Content Conventions

- Notes use LaTeX math via `$...$` (inline) and `$$...$$` (display) syntax, processed by remark-math/rehype-katex.
- Content is written in Japanese.
- Each doc directory uses `_category_.json` for sidebar ordering/labels and individual docs use `sidebar_position` frontmatter.
